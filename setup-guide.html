Install Backend Dependencies

Set up Python environment and packages

Create virtual environment:
# Navigate to project folder
cd voice-guard
# Create virtual environment
python -m venv sih_env
Activate environment:
# Windows:
sih_env\Scripts\activate
# Mac/Linux:
source sih_env/bin/activate
Install packages (takes 1-2 minutes):
pip install -r requirements.txt
Success Indicator:
You'll see "Successfully installed fastapi uvicorn torch transformers..." messages
2

Start the Backend Server

Launch the AI inference engine

Run the server:
python -m uvicorn server:app --reload
What to Expect:
1. "Initializing VoiceGuard ML Engine..." (5-10 seconds)
2. "Loading AI model into memory..." (10-30 seconds)
3. "Model loaded successfully!"
4. "Uvicorn running on http://127.0.0.1:8000"
Server is Ready!
Keep this terminal window open while using the app

Troubleshooting

❌ "Backend Disconnected" Error
• Ensure Python server is running
• Check terminal shows "Uvicorn running..."
• Verify no firewall blocking port 8000
• Test connection in Settings page
🎤 Microphone Not Working
• Click lock icon in browser address bar
• Ensure microphone permission is granted
• Refresh the page and try again
• Check system microphone is not muted
🐌 High CPU Usage
• This is normal - ML model is processing in real-time
• Increase chunk duration in Settings (2.5s → 3.0s)
• Close unnecessary browser tabs
• Ensure adequate RAM available (~2GB)
