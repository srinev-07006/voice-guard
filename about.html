About VoiceGuard

Real-time deepfake voice detection system

VoiceGuard

AI-Powered Real-Time Detection and Prevention of Voice Cloning Impersonation Attacks

Smart India Hackathon 2026 Problem Statement 26104 Team Domino

Key Features

Fast Path Detection

Wav2Vec2 transformer instantly identifies synthetic speech artifacts in 2.5-second windows

Context Analysis

Evaluates conversational context for social engineering patterns and urgent keywords

Decision Ladder

Three-tier risk categorization with actionable operator recommendations

Privacy by Design

DPDP Act 2023 compliant - audio processed in RAM, no files saved to disk

Safe Decision Ladder

🟢
LOW RISK - CONTINUE
Clean audio profile detected. Proceed with standard operations.
Threshold: <40% risk score
🟡
MEDIUM RISK - VERIFY
Elevated risk profile. Prompt caller with dynamic security questions or trigger callback.
Threshold: 40-70% risk score or context flagged
🔴
HIGH RISK - HOLD
Synthetic acoustic anomaly detected. Pause transaction and require secondary out-of-band verification.
Threshold: >70% risk score

System Architecture

1
Browser Capture
MediaRecorder API captures live microphone audio in 2.5s chunks (16kHz mono)
2
WebSocket Streaming
Real-time low-latency streaming to FastAPI backend via WebSocket connection
3
AI Inference
Wav2Vec2 model analyzes acoustic patterns and outputs deepfake probability
4
Risk Fusion
Combines acoustic score + context analysis into Decision Ladder recommendation
5
Dashboard Update
Real-time UI updates with risk score, action, and operator instructions

Privacy & Compliance

DPDP Act 2023 Compliant
Audio streams processed dynamically in volatile RAM using io.BytesIO
Zero Persistent Storage
No raw .wav files or recordings saved to disk at any point
Secure Transmission
WebSocket protocol for encrypted real-time communication
Local Processing
All inference happens on local infrastructure, no cloud API calls
